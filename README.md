# Robot Wars

A simple turn-based robot battle game built with Python.

## About

**Robot Wars** is a command-line game where robots battle each other in turn-based combat. Choose your robot, attack your opponent, and use your shield to survive the battle.

## Features

* Turn-based combat
* Robot battles
* Attack system
* Shield system
* Health system

## Requirements

* Python 3.x

## Run

```bash
python main.py
```
